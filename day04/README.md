# Day 4 – Data visualization

[Course overview](../README.md) · [Full program](../PROGRAM.md)

**12 November 2026**

Learn how visual properties shape the interpretation of data, how to choose graphs, and how scripting tools support visualization. Apply these ideas in a workshop using Claude.
